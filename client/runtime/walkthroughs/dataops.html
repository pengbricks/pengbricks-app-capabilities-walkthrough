The short version

  1. Environments differ by name, tag, and variables.

    One bundle has a dev and a test target. Test adds a [test] name prefix and an environment tag. Host, catalog, and alert address come from per-environment GitHub variables.

  2. Retries and alerts are part of the job.

    ingest_with_retry retries up to twice, 15 seconds apart. A failure or a run over 1,200 seconds emails the owner. Every deploy carries these settings.

  3. Run history and audit are SQL tables.

    audit_log, dataops_task_attempts, and dataops_run_history say who ran what and which attempt failed. DESCRIBE HISTORY covers data changes.

  4. Roll back data, redeploy code.

    A rollback job runs RESTORE TABLE to an earlier Delta version. For code, run reference-cicd with workflow_dispatch on an earlier commit.

Environment separation from one bundle

Two targets, one definition. The table shows what the bundle sets itself and what it leaves to GitHub environment variables.

Run history and audit trail

Operational history is stored as ordinary tables, so a reviewer can answer questions with SQL instead of reading logs.

Retry and alert path

A transient error is retried before anyone is bothered. If a run fails or runs long, the owner gets an email.

Rollback and redeploy

Data and code recover separately. Data goes back to an earlier Delta version. Code goes back by deploying an earlier commit.

Demo steps

  1. Show the targets. Open databricks.yml: dev in development mode, test with the prefix and tag.
  2. Show the job settings. Retries, notifications, health rule, timeout, and one run at a time are in dataops.job.yml.
  3. Run the job. ingest_with_retry fails once, waits 15 seconds, and passes on attempt 1.
  4. Query the audit tables. audit_log, dataops_task_attempts, and dataops_run_history.
  5. Read the data history. DESCRIBE HISTORY on transactions_silver.
  6. Roll back. Run the rollback job. Leave the version blank to undo the latest write, then check history for the RESTORE entry.
  7. Redeploy. Run reference-cicd on an earlier commit with workflow_dispatch.
